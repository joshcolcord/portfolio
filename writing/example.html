This is a placeholder article, sitting alongside the site it belongs to. It exists so the Works page has something real to point at while the actual writeups are being written — its job is to show the typography and spacing a finished piece will land in, not to say anything.

Body text runs at the same measure and leading as the home page, so a writeup reads as part of the same site rather than a separate artifact. Headings, lists, quotes and code all inherit the same palette, which means there is one file to edit when the colours change.

How these pages get made

The list of works on works.html is generated from works.json. Articles are written by hand; only the index is compiled. The build step checks that every article path in the JSON actually resolves on disk, so a typo shows up as a warning at build time rather than a 404 in the browser.

What is here

  • Paragraphs, links and headings, at the site's normal rhythm.
  • An home link, so a reader can get back out.
  • A back link to the works index.
Placeholder prose should look like the real thing at a glance, or it hides layout problems until the day you need it to not.
